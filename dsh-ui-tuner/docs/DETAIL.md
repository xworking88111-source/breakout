# 介面調整

左側欄的「介面調整」入口，把閱讀舒適度集中在一個頁面裡，不必改設定檔或重新載入。

## 功能

- **字級**：內容文字（10–22 px）、程式碼（10–16 px）、側欄終端機（10–20 px）各自以 `−`／`+` 調整。數值寫回介面設定，重新開啟仍然保留。
- **色調**：預設／柔白／暖砂／高對比四組預設，覆蓋底色、邊框、文字、輸入框、程式碼區塊與側欄底色（`--dsw-alias-*`、`--dsw-specific-*`），不動明暗主題。選擇記在目前瀏覽器，重新載入自動套用。
- **版面**：一鍵收合右側面板並回到對話，把空間還給對話內容；收合狀態記在目前工作階段。

## 使用

1. 左側欄點「介面調整」。
2. 用 `−`／`+` 把字級調到順眼；覺得背景刺眼時先試「柔白」。
3. 要回對話，按右上角「回到對話」或左側欄任一工作階段。

## 限制

- 只調整 DSH 提供的介面設定與主題 token，不做整頁縮放；訊息欄寬度仍用對話兩側的拖曳把手。
- 色調存在瀏覽器（localStorage），不同瀏覽器或無痕視窗不會共用。
- 右側面板的「收合」由版面動作完成；要再打開，用對話標題列右側的展開鈕。

## 移除

設定 → 外掛程式 → 介面調整 → 移除，或關閉它的列。字級與色調的變更屬於介面設定，移除外掛後仍保留，可在設定 → 外觀改回。
