# 03 · 數據源與合法性

> **English summary**
> The project runs on **free, keyless or free-tier sources only**. This document lists what is
> available, its limits and licence status, and sorts every source into green (official API /
> explicitly permitted), yellow (free but restricted or attribution required) and red (scraping
> prohibited / no public API). It also specifies the ETL stack (GitHub Actions + static JSON +
> optional DuckDB) and the minimum viable dataset for month one. Paid data (DataEye, Yunhe, Sensor
> Tower) is documented for future commercial use only and is **not** part of the free pipeline.

---

## 中文

### 1. 原則：全程免費、可公開重現

本專案承諾：

1. **不使用需要付費的 API 或 SaaS**（DataEye、雲合、Sensor Tower、Trakt 商用等一律不接）。
2. **不使用需要金鑰的服務**（AniList 免 key；不用 TMDB／YouTube 需要註冊的 key，除非未來有必要且仍免費）。
3. **托管與排程免費**：GitHub Pages + GitHub Actions（公開 repo）。
4. **不繞過反爬**：不破解簽名、不使用代理池、不偽造指紋。
5. **不鏡像**：只儲存衍生統計（排名、分數、類別佔比），不存原始榜單全文、封面圖、文章全文。

### 3. 合法性框架

- **robots.txt 是慣例，不是授權**；違反 ToS 屬民事違約；繞過技術保護措施在台灣可能觸犯刑法妨害電腦使用罪章。
- **著作權**保護「資料的選擇與編排」（編輯著作）；純事實與排名是否受保護仍有爭議。
- **歐盟資料庫權利**（sui generis）保護對資料庫的實質投資，跨境服務需注意。
- **降低風險的做法**：
  1. 優先官方 API 與付費授權（未來）。
  2. 只存衍生統計，不存原始榜單快照。
  3. 標註來源、抓取時間與「非官方」聲明。
  4. 遵守 `Retry-After`、嚴格 rate limit、指數退避。
  5. 提供更正與下架管道。
  6. 不做全文轉載與圖片鏡像。

> 本專案目前的短劇／小說／電影資料是「**人工閱讀公開報導後整理的編輯資料**」，不是爬蟲抓取的榜單鏡像。這是刻意的合規選擇，也是資料量較少的原因。

### 4. ETL 技術鏈路（全免費）

```
GitHub Actions（每週一）
   │
   ├─ node scripts/fetch_anilist.mjs   → app/src/data/anime.json（實測快照）
   │
   ├─ node scripts/build_dataset.mjs   → app/public/data/works.json（合併 + 計分）
   │
   ├─ node scripts/validate_dataset.mjs（失敗則 CI 擋下）
   │
   └─ git commit + push → 觸發 deploy.yml → GitHub Pages
```

- **儲存**：靜態 JSON（MVP）。資料量超過 10 萬筆再考慮 DuckDB（本機分析）或 Supabase 免費層。
- **轉換**：純 Node 腳本，無需 dbt／Airflow。
- **排程**：GitHub Actions cron（公開 repo 免費；注意單次 6 小時上限）。
- **快取**：無需 Redis；Pages 自帶 CDN。
- **監控**：validator + CI 紅灯即告警。

## English (full version)

### 1. Free-only policy

1. No paid APIs or SaaS (DataEye, Yunhe, Sensor Tower, commercial Trakt are excluded).
2. No key-required services in the default pipeline (AniList needs no key).
3. Free hosting and scheduling: GitHub Pages + GitHub Actions on a public repo.
4. No bypassing anti-bot measures, no proxy pools, no fingerprint spoofing.
5. No mirroring: store derived statistics only (ranks, scores, category shares), never raw chart dumps, cover art or article text.

### 2. Source list

**Green (official API / permitted)**: AniList GraphQL (90 req/min), Jikan v4 (3 req/s), Open Library (1 req/s), Google Books (1,000/day), official box-office statistics and Wikipedia.

**Yellow (free but restricted)**: MyAnimeList API v2 (OAuth, undocumented limits), TMDB (non-commercial free, 6-month cache limit), OMDb (1,000/day), Reddit (100 QPM), YouTube Data API (10,000 units/day), public in-app charts from Hongguo/Douyin/Kuaishou (manual, low frequency), DataEye public reporting.

**Red (excluded)**: Douban (no API, ToS prohibits scraping), Maoyan/Lighthouse (no public API), Yunhe (paid), Sensor Tower/Appfigures (paid), Qidian/Fanqie/Qimao/Jinjiang charts (ToS prohibits scraping), Bilibili unofficial endpoints, Baidu Index, paid DataEye tiers.

### 3. Legal framework

robots.txt is a convention, not a licence. Violating ToS is a contractual breach; bypassing technical protection measures may be a criminal offence in Taiwan. Copyright protects the selection and arrangement of data; database rights (EU sui generis) protect substantial investment. Mitigations: prefer official APIs, store derived statistics only, attribute sources and crawl times, respect `Retry-After`, rate-limit aggressively, provide correction/takedown channels, never mirror full text or images.

The current short-drama/novel/film records are **editorial summaries written after reading public reporting**, not scraped chart mirrors. That is a deliberate compliance choice and the reason the catalogue is small.

### 4. ETL (all free)

GitHub Actions (weekly) → fetch AniList → build dataset → validate → commit → deploy to Pages. Static JSON in the MVP; DuckDB locally or Supabase free tier if the dataset grows past ~100k rows. No dbt, no Airflow, no Redis, no paid monitoring — the validator and CI are the monitoring.

### 5. Minimum viable dataset for month one

500 anime from AniList; 100 short dramas from public reporting (manual); 100 films from official box office/Wikipedia; book metadata from Open Library/Google Books; YouTube view counts as a short-drama proxy; weekly automated refresh. Unavailable: true revenue share, completion rate, retention, ad spend, algorithm weights — use proxies and label them `estimated` (see docs/02 §6).
