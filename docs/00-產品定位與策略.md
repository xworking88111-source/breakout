# 00 · 產品定位與策略

> **English summary**
> Breakout is a cross-media breakout index, not another streaming or review site: a data terminal
> where short dramas, anime, novels and films share one explainable ruler. Three audiences — casual
> viewers deciding what to watch, data workers needing comparable and exportable numbers, and
> researchers needing citable snapshots — all want the same thing: a trustworthy *relative
> position*. IMDb's four structural gaps (no explanation, no short drama, no cross-media
> comparability, no citable snapshots) define the wedge. The product has three layers: entry
> (charts), explanation (title pages), trust (methodology + research mode). The business model must
> never sell rankings; authority is the moat.

## 1. 一句話

**Breakout 破圈** 是一個「跨媒介爆款數據站」：把短劇、動漫、小說、電影放進同一套可解釋的指數，用一屏告訴你「現在什麼厲害、為什麼」，並把方法論與原始資料開放給研究者。

不是另一個串流平台，也不是另一個豆瓣。是**內容市場的 Bloomberg 終端（簡化版）**：榜單是入口，解釋是產品，方法論是護城河。

---

## 2. 客群與工作（Jobs To Be Done）

| 客群 | 他們的工作 | 現在怎麼解 | 痛點 |
|---|---|---|---|
| **想知道什麼好看的人**（最大盤） | 「今晚兩小時，看什麼不踩雷？」 | 豆瓣／IMDb／朋友推薦／平台首頁 | 選擇成本高、評分通膨、平台首頁是廣告位 |
| **數據工作者**（增長引擎） | 「把內容熱度變成可比較、可匯出的資料」 | 手動截榜單、Excel、付費 SaaS | 口徑不一、無歷史快照、無法引用 |
| **研究者**（權威來源） | 「短劇爆款的因素是什麼？可不可以重現？」 | 訪談、個案、付費報告 | 沒有公開、可驗證、帶版本號的資料集 |

**核心洞察**：這三類人其實要同一件事——**一個可信的「相對位置」**。一般觀眾要「這部在同類裡排第幾」，數據工作者要「這個排名的口徑與誤差」，研究者要「這個排名是怎麼算出來、能不能引用」。所以產品的第一性不是「更多內容」，而是**可比較性 + 可解釋性 + 可追溯性**。

---

## 3. 定位宣言

> 給想要快速判斷「什麼值得看」的人與需要引用內容數據的研究者，
> **Breakout** 是一個跨媒介的爆款指數與解釋層。
> 有別於 IMDb 只給分數、豆瓣只給中文文藝圈口碑、DataEye 只給中國短劇付費榜，
> 我們**用同一把尺量不同媒介、把每個分數拆成可解釋的因素、並公開公式與資料截止日**。

---

## 4. 「超越 IMDb」不是口號，是四個結構性缺口

IMDb 很強，但它的設計目標是「電影資料庫 + 評分」，不是「幫你決定看什麼」。它的四個缺口正好是我們的切入點：

| IMDb 的缺口 | 為什麼存在 | Breakout 的做法 |
|---|---|---|
| **只給分數，不給原因** | 評分是使用者行為的聚合，沒有內容層與機制層資料 | 五維拆解 + 「為什麼火」瀑布圖 + 編輯註記與來源 |
| **短劇完全缺席** | 短劇是 2023 年後的新物種，且主要在中國／東南亞 | 以短劇為第一賽道，建立產業標準（這是最大差異化） |
| **跨媒介不可比** | 電影／影集／動畫分開計分，量級不同 | 以「同類相對位置」為語義的 0–100 絕對刻度 |
| **研究者不可引用** | 無公開公式、無資料快照、無 API | 版本化快照、區間估計、CSV、方法論頁、引用格式 |

**但要誠實**：短期內我們不可能在「電影資料庫完整性」上超越 IMDb（那是 30 年、數百萬條目的護城河）。合理的目標是：

1. **在短劇賽道**成為事實標準（目前全球沒有公認的短劇評分體系）。
2. **在「可解釋性」**上超越所有現有站點（IMDb、豆瓣、Bangumi 都做不到）。
3. **在華語＋國際雙語**上建立橋樑（繁中市場長期缺乏國際級數據站）。

## 5. 產品三層架構

```
┌─────────────────────────────────────────────┐
│  L1 入口層：榜單 + 推薦                        │  一般使用者，一屏解決
│  今日焦點 / 正在爆 / 破圈榜 / 3 秒選片          │
├─────────────────────────────────────────────┤
│  L2 解釋層：作品詳情                            │  進階使用者，回答「為什麼」
│  五維雷達 / 瀑布圖 / 熱度曲線 / 相似作品 / 來源   │
├─────────────────────────────────────────────┤
│  L3 信任層：方法論 + 研究者模式                  │  數據工作者與研究者
│  公式 / 權重 / 限制 / 快照 / CSV / 引用 / API    │
└─────────────────────────────────────────────┘
```

**關鍵設計**：L3 不是「關於我們」的裝飾頁，而是產品的差異化核心。每次 L1 顯示一個數字，都必須能在兩次點擊內到達 L3 的口徑說明。這叫「可解釋性契約」。

---

## 6. 針對「大陸 App 很雜亂」的解法

使用者原話是「功能很多很厲害但很雜亂」。拆開來看是三件事：

1. **推銷邏輯 vs 比較邏輯**：首頁是金剛區 + 活動彈窗 + 金幣任務，因為平台要的是停留與轉化，不是幫你決策。
2. **資訊層級過深**：榜單藏在三級頁，且預設是推廣位。
3. **廣告與內容難辨**：原生廣告混入資訊流。

我們的反向設計（已落實在 MVP）：

| 他們的問題 | 我們的原則 |
|---|---|
| 首頁入口爆炸 | **一屏一任務**：首頁只答「今天什麼值得看」 |
| 封面／海報搶眼但無資訊 | **數據先於封面**：分數、狀態、動能放第一行 |
| 金幣、簽到、任務 | **零任務、零彈窗**：不做成癮設計 |
| 榜單藏在深處 | **兩次點擊可達**：任何作品 ≤ 2 點擊；篩選寫進 URL |
| 數字沒有口徑 | **可解釋優先**：每個指標可點開看來源、樣本、截止日 |

還有一個容易被忽略的點：**「簡化」不是「減少功能」，而是「減少決策成本」**。所以我們保留篩選、比較、匯出這些「進階功能」，但把它們放在 L2/L3，讓一般使用者第一眼只看到三個數字：**分數、排名、為什麼**。

## 7. 北極星指標與護城河

**北極星**：每週「因為看到分數而做出觀看決定」的次數（可用 outbound click 到平台／預告 proxy）。

**二級指標**：
- 內容覆蓋：短劇 ≥ 500 部、動漫 ≥ 3,000 部、小說 ≥ 1,000 部
- 資料新鮮度：榜單类指标日更、作品頁週更
- 解釋使用率：詳情頁「為什麼火」區塊的展開率
- 研究者使用：CSV 下載數、引用數、API 呼叫數
- 雙語平衡：英文流量占比（目標 30%+）

**護城河（依可持續性排序）**：
1. **方法論與歷史快照**：越早開始記錄，越難被追上（時間是不可複製的資產）。
2. **短劇標準制定權**：如果業界開始引用「Breakout 指數」，就是標準。
3. **雙語內容對照**：華語作品的正確英譯、國際作品的繁中譯名，是苦工也是壁壘。
4. **研究者社群**：可引用的資料集會產生論文與報導，形成權威飛輪。

**不是護城河**：榜單本身（誰都能抄）、UI（會被模仿）、推薦演算法（資料不足時無效）。

## 8. 商業模式（建議）

| 模式 | 對象 | 價格假設 | 風險 |
|---|---|---|---|
| **免費 + 廣告** | 一般使用者 | CPM 低，但可維持 | 破壞簡潔體驗 → 建議只做「非侵入式」 |
| **Pro 訂閱** | 數據工作者 | US$8–12/月 | 需要歷史資料、匯出、警示 |
| **B2B 儀表板 / API** | 製作公司、平台、投資人 | US$500–5,000/月 | 需要穩定資料源與 SLA |
| **資料授權 / 報告** | 研究機構、媒體 | 按報告計價 | 需方法論權威性 |
| **聯盟導流** | OTT / 平台 | 按轉換 | 需揭露商業關係 |

**不可以做**：賣排名、賣評分、接受平台「優化」分數。一旦做了，L3 信任層就崩了，整個產品歸零。

## 9. 主要風險與對策

| 風險 | 等級 | 對策 |
|---|---|---|
| 資料合法性（爬蟲／榜單轉載） | 🔴 高 | 只用公開 API + 衍生統計；付費授權優先；不做全文／鏡像；見 docs/03 |
| 短劇資料不可得（平台封閉） | 🔴 高 | 多源代理指標（YouTube、App 榜、新聞稿）；先做「估算 + 透明標記」 |
| 刷分／買榜污染 | 🟠 中 | 貝氏收縮、樣本門檻、分布異常偵測、公開剔除紀錄 |
| 樣本偏差（AniList 英語圈） | 🟠 中 | 標明偏差；接入 Bangumi／MAL 交叉驗證 |
| 內容同質化（大家都在做榜單） | 🟠 中 | 差異化在「解釋」與「方法論」，不在榜單 |
| 法律與政治敏感（中國內容） | 🟠 中 | 不做政治評論；以數據與產業分析為主；地區合規 |
| 創作者反彈（被評分） | 🟡 低 | 提供申訴與更正管道；分數與「編輯推薦」分離 |

## 10. 命名與品牌（工作名）

目前工作名 **Breakout / 破圈**。

| 候選 | 優點 | 缺點 |
|---|---|---|
| **Breakout 破圈**（目前） | 中英皆可直接用、語義就是「爆款」、短 | 「破圈」在中文已有通用語義，商標可能擁擠 |
| HitRank | 直白、SEO 友善 | 太像工具站，缺品牌感 |
| Signal / 信號 | 高級、適合數據客群 | 太抽象，一般使用者無感 |
| 一屏 OneScreen | 呼應「簡潔」定位 | 不像數據品牌 |
| 燈塔 | 權威感 | 與阿里「燈塔專業版」衝突 |

建議：**品牌用 Breakout，中文副標「破圈指數」**，產品名與指數名分離（像 IMDb 與 IMDb Rating）。
