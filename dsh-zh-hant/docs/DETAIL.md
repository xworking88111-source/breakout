# 繁體中文語言包

DSH 內建只有 `zh`（簡體）與 `en` 兩種基準語言，語言選單沒有繁體。這個 bundle 用官方擴充點補上 `zh-Hant`。

## 功能

- 註冊語言 `zh-Hant`，名稱顯示為「繁體中文」，fallback 為 `zh`。
- 把 DSH 目前版本所有用戶端介面字典（73 個命名空間、3882 條字串）用 OpenCC `twp`（台灣用語，例如「設定」「軟體」「匯出」「程式碼」）轉成繁體後重新註冊。
- 未涵蓋的命名空間或新增字串會回退到簡體 `zh`，不會出現英文或空白。

## 使用

1. 設定 → 一般 → **語言**，選 **繁體中文**。
2. 選擇會寫回介面設定，重開 App 仍保留；要換回簡體就選「中文」。

## 涵蓋範圍

側欄、對話與輸入框、設定各頁、外掛管理、右側面板（檔案／瀏覽器／終端機／文件預覽）、排程、工作、子代理、軌跡、權限、模型選擇、指令選單等，共 73 個命名空間；外掛管理頁顯示的外掛名稱與描述屬資料層（Locale 資源），由各外掛自己的 `locale/*.json` 提供，不在本包轉換範圍。

## 限制

- 翻譯是機器轉換（OpenCC s2twp），不是人工校稿；專有名詞仍以原文為準。
- 只影響介面文字；會話內容、模型輸出與你自己的工作區／會話名稱不會被改寫。
- DSH 升級後若有新增字串，會以簡體顯示；重新執行 `tools/extract.mjs` + `tools/build.mjs` 即可更新本包。

## 建置

```sh
ELECTRON_RUN_AS_NODE=1 "$DSH_NODE_EXECUTABLE" tools/extract.mjs   # 從已安裝套件原始碼抽字典 → /tmp/dsh-zh-pack.json
node tools/build.mjs                                              # 轉繁體並產生 client.js（需 opencc-js）
```
